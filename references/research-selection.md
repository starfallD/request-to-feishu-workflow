# Research skill selection

Use this reference after `find-skills` returns candidate skills.

## Selection order

1. Match the candidate to the subject and source type.
2. Prefer official maintainers, clear documentation, recent updates, and evidence of use.
3. Prefer a focused skill over a broad bundle when both cover the same task.
4. Choose one primary collector; add `agent-browser` only for navigation, dynamic pages, screenshots, or source verification.
5. Record the selected skill, fallback, and reason in the working notes or report.

## Evidence handling

For current or consequential claims, prefer primary sources such as official announcements, papers, government or regulator pages, and original datasets. Use secondary reporting to discover leads or add context, not to replace a missing primary source when the claim matters.

For every retained item, capture the title, publisher, publication date, URL, claim supported, and any uncertainty. Deduplicate items that repeat the same announcement.

## Do not install by default

Use an already installed skill when it is adequate. Ask for installation only when the user explicitly requests it or when the task cannot be completed with the available skills.
